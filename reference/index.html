Sainté Speed — planche de références façades

Chaque archetype de façade du jeu, peint par le même code que la scène (src/lib/facades.ts), face aux photos du vrai Saint-Étienne qui ont servi à le caler. Les photos viennent de Wikimedia Commons (licence et auteur sous chaque image, détail dans reference/photos/manifest.json). Pour les rafraîchir : npm run fetch-reference.
